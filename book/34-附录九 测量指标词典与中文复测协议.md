# 附录九 测量指标词典与中文复测协议

本附录汇总正文各章传播效果测量指标的操作定义，并给出面向中文平台生态的复测协议。复测协议依据正文第二章、第三章GEO讨论：选取文心一言、通义千问、Kimi、豆包、DeepSeek等主流中文模型，编制标准化提问集，对“优化前/优化后”两组内容做A/B对照，实测首提率与引用率差异。

## 一、测量指标词典

附表I-1　传播效果测量指标词典（汇总正文各章）

| 指标 | 操作定义 | 测量方法 |
|---|---|---|
| AI提及率 | 核心实体在AI回答中被提及的频率 | 多模型提问测试 |
| AI首提率 | 用户问到相关品类时AI首先提及你的概率 | 标准化提问集测试 |
| AI引用率 | 你的内容在AI答案中被引用的频率 | 引用监测 |
| 转述准确率 | AI转述与核心主张的匹配度 | 语义一致性编码 |
| 联想准确率 | 受众对核心叙事的准确联想率 | 抽样调查 |
| 信任度得分 | 受众对主体的信任评分 | 量表评分（0-10） |

## 二、中文复测协议

附表I-2　中文GEO复测协议（依据正文第二章、第三章）

| 步骤 | 核心动作 | 说明 |
|---|---|---|
| 模型清单 | 文心一言·通义千问·Kimi·豆包·DeepSeek | 覆盖主流中文模型 |
| 提问集编制 | 编制标准化提问集 | 覆盖高频问答场景 |
| A/B对照 | 优化前/优化后两组内容 | 对照组设计 |
| 实测 | 实测首提率与引用率差异 | 多平台多次测试 |
| 结论 | 以本土数据校准策略权重 | 持续迭代 |

使用提示：中文场景的模型生态、检索机制与语料分布与英文环境存在差异，英文实验数据不可直接外推，须以本协议本土复测结果为准。
